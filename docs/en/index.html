04 / ANDROID 8.0+

Android requirements

Android 8.0 or later (API 26). A signed APK for direct installation. The banking edition requires connectivity and, when requested by the bank, device approval and operation authorization. Never enter credentials on this website.

Privacy

Privacy · Android APK

How to install

  1. Choose the offline demo, or read the experimental banking edition’s limitations before downloading it.
  2. Download the APK and SHA-256 checksum file for the same version. Compare the file’s checksum before installing.
  3. Open the APK. If Android asks, allow installation from the app you used to download it. Disable that permission afterwards.
  4. Open the app and read its notices and terms. The demo uses fictional data only; the banking edition retains the bank’s access and authorization controls.
  5. The banking APK keeps com.santacruz.modern and uses a dedicated distribution key. It cannot update a Santa Cruz Modern installation signed with another key. If Android blocks the update, preserve the existing app and its data; use the separate demo or contact support.

Help and feedback

Report app issues to bluegrain.lcc@gmail.com. Do not send passwords, codes, identity documents or account details. For banking support, use the bank’s official channels.

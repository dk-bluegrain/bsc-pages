Edição bancária experimental

Aplicativo independente com conexão bancária configurada. A autorização do banco e a validação com a conta de seu titular continuam pendentes. A compatibilidade atual com o serviço do banco não foi estabelecida.

Ler o guia e os riscos ↗

Versão 1.12.2 (29) · SHA-256 · GitHub Release

A edição bancária é independente e experimental. A autorização do banco e a validação com uma conta de seu titular continuam pendentes. Restaurar a configuração não comprova que o acesso funciona. Este não é um aplicativo oficial nem uma publicação no Google Play.

Requisitos do Android

Android 8.0 ou posterior (API 26). APK assinado para instalação direta. A edição bancária exige conexão e, quando solicitado pelo banco, aprovação do dispositivo e autorização das operações. Nunca insira credenciais neste site.

Privacidade · Android APK

Como instalar

  1. Escolha a demonstração offline ou leia as limitações da edição bancária experimental antes de baixá-la.
  2. Baixe o APK e o arquivo de somas SHA-256 da mesma versão. Compare a soma do arquivo antes de instalar.
  3. Abra o APK. Se o Android solicitar, permita a instalação pelo aplicativo que você usou para baixar o arquivo. Depois desative essa permissão.
  4. Abra o aplicativo e leia os avisos e termos. A demonstração usa apenas dados fictícios; a edição bancária mantém os controles de acesso e autorização do banco.
  5. O APK bancário mantém com.santacruz.modern e usa uma chave de distribuição própria. Ele não atualiza uma instalação do Santa Cruz Modern com outra assinatura. Se o Android bloquear a atualização, preserve o aplicativo existente e seus dados; use a demonstração separada ou entre em contato com o suporte.

Ajuda e comentários

Relate problemas do aplicativo para bluegrain.lcc@gmail.com. Não envie senhas, códigos, documentos de identidade ou dados da sua conta. Para atendimento bancário, use os canais oficiais do banco.

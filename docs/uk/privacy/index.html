Конфіденційність сайту й застосунку

Цей статичний сайт представляє застосунок. Сайт, демоверсія без підключення до банку та банківська версія обробляють різні дані, як описано нижче.

Статичний сайт

На сайті немає банківського входу, форм для облікових даних, аналітики чи власного серверного застосунку. Вибір мови й відтворення матеріалів відбуваються в браузері. Не вводьте тут банківські дані.

Хостинг і зовнішні посилання

Сайт розміщено на GitHub Pages, APK розповсюджуються через GitHub Releases. GitHub може обробляти дані підключення, зокрема IP-адреси й журнали запитів, за власною політикою. Посилання на підтримку, банк та інші сервіси ведуть до зовнішніх ресурсів із власними умовами.

Демоверсія без підключення до банку

Демоверсія використовує вигадані особи, рахунки й операції та не підключається до банку. Зміни зберігаються локально. Скидання демоверсії або очищення даних застосунку видаляє цей стан; видалення застосунку видаляє його приватні дані. Експортовані в інше місце файли можуть залишитися там.

Банківська версія

Під час використання банківських функцій застосунок надсилає запити до банку. Якщо ви вибираєте збереження доступу, облікові дані шифруються за допомогою Android Keystore та потребують сильної біометричної автентифікації. Підключення токена вимагає явної згоди з договором і зашифрованим зберіганням секретного ключа. Сеанси та створені коди не зберігаються постійно. Повний опис обробки даних наведено в політиці всередині застосунку.

Файли та служби пристрою

Для перегляду виписок використовується приватний кеш. PDF, збережені у вибране місце, можуть залишитися після виходу чи видалення застосунку та синхронізуватися відповідно до налаштувань постачальника. Під час надсилання PDF, CSV або QR файл отримує вибраний застосунок; збережені ним копії регулюються його правилами. Для зовнішньої перевірки особи та модулів Android чи Google в необов’язкових функціях діють окремі умови.

Обмеження та контакт

Застосунок є незалежним та експериментальним. Дозвіл банку й перевірка з рахунком його власника залишаються відкритими питаннями; поточна сумісність не підтверджена. Подання до Google Play до цієї роботи не входить. Контакт: bluegrain.lcc@gmail.com. Не надсилайте облікові дані чи особисту банківську інформацію.

Why a direct APK download?

From the developer: I cannot offer this project through Google Play or other app stores because, in my understanding, publishing this independent client would conflict with Banco Santa Cruz’s terms and conditions. The bank has not authorized this project. Direct distribution does not resolve that conflict or give you permission from the bank. Review the terms that apply to your account; if you are unsure, use the bank’s official channels.

An APK is an Android installation file. Because you download it from GitHub rather than an app store, Android requires permission for the browser or file manager opening it to install apps from that source. This is permission for that installer, not banking access for Santa Cruz Modern. It is needed only for installation or updates; turn it off afterwards. It does not require rooting your phone.

What I do to protect the release

I build and distribute this application with security in mind. I do not intentionally include viruses, malware, spyware or code designed to steal your information. The releases are digitally signed with the project’s distribution key, and I publish SHA-256 checksums so you can compare your download with the released file.

These safeguards are not an independent security audit or a guarantee that the app, its dependencies, your device or the distribution channel is free of vulnerabilities or malicious compromise. A matching checksum confirms that the file matches the published release; it does not prove that the software is safe. Read the APK privacy notice for credential, token and file handling before signing in.

Install on Android, step by step

For Android 8.0 or later. The same installation permission applies to both APKs. Read the additional real-banking disclosures above before downloading the unofficial edition.

Actual Android 15 emulator screenshots, shown in English with a demo APK. Your phone’s wording, browser and layout may differ. Tap an image to enlarge it. No bank account or real transaction is used.

  1. Choose and verify your APK

    Use only the links on this page to the project’s GitHub Release. Check the edition, version and filename, then compare the downloaded file’s SHA-256 with SHA256SUMS from that same release. If they differ, do not install. Both apps need about 77 MB to download; installation needs additional space.

  2. Open the downloaded file

    On your Android phone, open the APK from your browser’s Downloads or a file manager. If Android blocks this source, choose Settings in the prompt. You can also search Android Settings for “Install unknown apps” (often under Apps → Special app access) and select the browser or file manager that opened the APK.

  3. Allow only this source, temporarily

    Read Android’s warning. If you choose to continue, enable “Allow from this source” for the specific browser or file manager. The screenshot shows an example browser. Do not enable unrelated sources. Return to the APK to continue.

  4. Review the installer and install

    Check that you selected Santa Cruz Modern and the correct APK edition, then tap Install. The screenshots use the separate demo package. A banking installation can work with real data and money; the demo cannot. Allow any security scan to finish; stop if a harmful-app warning appears.

  5. Turn the installation permission back off

    After installation, return to the same “Install unknown apps” screen and disable “Allow from this source”. The installed app can still run. For a future update, download from the same project release channel and repeat the temporary permission step.

  6. Read the app notices before use

    Open the app and read its terms and privacy notice before accepting. The demo uses fictional data; never enter real banking credentials there. Only the unofficial banking app is intended for real accounts, subject to bank checks and the risks above. If an update has a conflicting signature, keep the existing app and its data: do not uninstall to force it, because token state and uncertain-operation records could be lost. Use the separate demo or contact project support.

Keep Google Play Protect enabled. If Android offers a scan, let it complete and review the result. If the app is flagged as harmful, stop and contact the project; do not disable protections or bypass a harmful-app warning. If device policy or Advanced Protection blocks installation, use official banking channels.
